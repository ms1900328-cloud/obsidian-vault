O Jarvis tem acesso a um repositório GitHub que serve como intermediário para sincronizar as notas com o Obsidian. Qualquer modificação que o Jarvis fizer via tool_code.vault_write() neste repositório será refletida no vault Obsidian do usuário. O Obsidian, por si só, não faz a sincronização automática, mas ao puxar o repositório atualizado, as notas ficam sempre sincronizadas. Isso significa que o usuário não precisa se preocupar em atualizar manualmente; as notas serão automaticamente atualizadas no Obsidian ao sincronizar o repositório. Qualquer comando que eu (Jarvis) executar que envolva escrita no vault será feito através do GitHub, e o usuário terá o conteúdo atualizado em seu Obsidian.
